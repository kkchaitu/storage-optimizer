# Storage Optimizer

A SwiftUI-based iPhone utility app designed to help users reclaim storage space by identifying duplicate files, blurred photos, and large media assets.

## Workspace Setup

This workspace contains the app source code and asset catalog for a SwiftUI iPhone app.

### What’s included

- `StorageOptimizerApp.swift` – App entry point
- `ContentView.swift` – Dashboard and navigation
- `DashboardView.swift` – Storage health overview
- `ReviewView.swift` – Item review and deletion flow
- `SuccessView.swift` – Cleanup confirmation screen
- `Theme.swift` – Design tokens and reusable styling
- `Models/` – App data models and sample content
- `Assets.xcassets/` – Placeholder asset catalog

### Opening the project

1. Open Xcode.
2. Create a new iOS app project and add these files to the project.
3. Set the deployment target to iOS 17 or newer.
4. Add the `Assets.xcassets` folder to the app target.
